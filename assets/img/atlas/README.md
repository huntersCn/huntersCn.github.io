# Icon atlas

Game UI / monster / status / equipment icons cut from the supplied atlas sheets.

## Layout

- `cut/keyboard/` — keyboard keys, input prompts, weapon and small action icons.
- `cut/ui-gray/` — grayscale menu / system / facility icons.
- `cut/monsters/` — monster, weapon, armor and NPC icons.
- `cut/status/` — element, ailment, small monster and fish icons.
- `cut/ui-color/` — colored UI / status icons.
- `cut/icons8/` — quest rank / facility icons.
- `cut/equipment/` — armor, charm, decoration and equipment icons.
- `preview/` — contact sheets with the numeric filename under each icon.

Files are numbered per sheet. Use the contact sheet to find the number, then open `cut/<sheet>/<number>.png`.
Some adjacent pairs were split manually and use suffixes such as `004a.png` / `004b.png`.

## Favicon

The site favicon is `cut/monsters/076.png` (blue unknown-monster icon with a question mark).
The generated favicon files are in `assets/img/favicons/`.
